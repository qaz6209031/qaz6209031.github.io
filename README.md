### Analytics

Google Analytics 4 uses the **Kai-Chin Personal Website** property and the
**Kai-Chin Personal Website Web** stream, with measurement ID `G-2B46VSS4B1`.
The asynchronous tag in `index.html` collects only on `kaichin.dev/` and
`kaichin.dev/index.html`. Local previews, GitHub's alternate hostname, and other
projects such as `/bike/` do not collect data in this property.

Enhanced measurement tracks page loads, scrolls, and outbound clicks, including
project and social links. GA4 also reports traffic sources, engagement, and device
categories (desktop/mobile/tablet). Browser-history page views are disabled so
section navigation does not inflate page views. Google signals and ad
personalization signals are disabled.

After deploying, open [kaichin.dev](https://kaichin.dev/) and check
**Kai-Chin Personal Website → Reports → Realtime**. Device categories are under
**Reports → User → Tech**. Pushing to `master` deploys through GitHub Pages.
